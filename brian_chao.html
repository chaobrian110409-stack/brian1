Project 02 / Physics 2026.02

二維拋體與空氣阻力數值模擬

運用 Python 與歐拉法（Euler method）模擬不同空氣阻力係數下的拋體軌跡，並結合 Tracker 軟體分析實際慢動作錄像數據，探討雷諾數臨界效應。

Python NumPy / Matplotlib Kinematics
Project 03 / English 2025.12

Academic Writing GEPT Vocab Corpus Analysis
